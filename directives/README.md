# directives/

SOPs en Markdown (Capa 1 de la arquitectura: Qué hacer).

Cada directiva define, para una tarea o flujo concreto:
- Objetivo
- Entradas
- Herramientas/scripts de `execution/` a usar
- Salidas esperadas
- Casos extremos conocidos

Las directivas son documentos vivos: se actualizan a medida que se descubren restricciones de API, mejores enfoques o errores comunes. No crear ni sobreescribir directivas sin preguntar, salvo instrucción explícita.
